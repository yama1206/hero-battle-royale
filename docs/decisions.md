# りょうさんの決定（仕様書との差・補足）

- マップの広さはソルティア（16000）基準のまま（仕様の2400ではない）
- ダウンシールドは常に展開（仕様のボタン式にしない）
- 距離の数値（武器の射程・弾速、出撃距離、能力の範囲・移動距離）は仕様の約0.6倍。比率は保つ
  - 例：出撃 敵最低500→300、味方半径120→72／索敵パルス500→300、ブーストダッシュ350→210、ヒールフィールド180→108 など
- 安全地帯の最初の円はマップ全体を囲む円。そこから面積75%→55%→35%→18%→8%→消滅（面積はマップ全体比）
  - 縮小の始まる時刻は表の時刻（1:00, 3:00, 5:00, 7:00, 9:00）と読んで実装。各60秒で縮小、10:00で消滅
- BOTの「相手の画面に映っているときだけ撃つ」は、BOT作り直し（段階7）まで残す
